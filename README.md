# 🏋️ TYNTRA – Workout Planner App

> **Plan. Train. Transform. 💪**

TYNTRA is a simple and user-friendly Android application designed to help users plan, manage, and track their workouts. The application allows users to create an account, add workout details, view workout history, edit existing workouts, and delete completed or unwanted workouts.

The project is developed as a **Mobile Application Development (MAD) Micro Project** using Android Studio, Java, XML, and Firebase.

---

## 📱 About TYNTRA

TYNTRA provides a simple digital solution for managing workout routines.

Instead of maintaining workout details manually, users can store their exercises in the application and access their workout history whenever needed.

### ✨ Main Features

- 🔐 User Registration & Login
- 👤 User Profile Management
- 🏠 Workout Dashboard
- ➕ Add Workout
- 👀 View Workout History
- ✏️ Edit Workout
- 🗑️ Delete Workout
- 🔢 Track Sets and Repetitions
- 📅 Store Workout Date
- 🔥 Firebase Authentication
- ☁️ Cloud Firestore Database
- 🔒 Secure Firestore Rules
- 🎨 Modern Dark Fitness UI
- 🚀 Splash Screen with TYNTRA Branding
